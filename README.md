# Hollywood Animal Planner

A tool for [Hollywood Animal](https://store.steampowered.com/app/2680550/Hollywood_Animal/): pick tags for target Movie Score, check synergies and conflicts, plan releases. Load a save file to use tags from it, view raid/trial intel, and link your in-game movies to planning scripts.

This is a rewritten and extended version of [CallOn84/Hollywood-Animal-Calculator](https://github.com/CallOn84/Hollywood-Animal-Calculator/).

**Try it:** [https://userbig.github.io/hollywood-animal-planner/](https://userbig.github.io/hollywood-animal-planner/)
